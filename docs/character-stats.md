# Character stat kernel

The known-field domain kernel recovers SkillEffect.ApplyStatSkills: five primary skill bonuses, ATK/MATK/DEF/HP, critical chance/damage, rank sum and stone-skin armor definitions. Integer additions/subtractions wrap as in the original unchecked Int32 operations. Ratios have the original upper cap without an invented lower cap. CLR float-to-Int32 conversion retains the measured out-of-range sentinel rather than Rust saturating casts.

Arithmetic is explicitly Framework x86 or x64. The original extracted method produces different results in 288 of 800 synthetic cases across these architectures. The port compares all 25 fields, armor maps and destroyed DEF against each architecture independently; it does not silently choose the host Rust arithmetic. The future actor must bind the measured legacy arithmetic profile.

CharacterStats is a case-insensitive string dictionary in the source. This kernel admits only its 25 known enum fields; arbitrary extra string fields and arbitrary override keys are outside its scope. Base, item and status contributions are separate explicit inputs and merge with unchecked addition. No missing contribution is inferred as zero.

ApplyItemSkills is recovered only for a proven empty equipped-item collection: copy the supplied set bonus, zero weight and empty armor maps. Initial GiveItem stores equippables without a Part; loading/equipping those items remains separate. A caller must establish empty Gear; missing or failed equipment loading is not evidence of emptiness. Equipped armor/weapon/avatar effects, durability, load thresholds/penalty and content queries remain pending. The oracle includes the entire original item method but its equipment/content helpers throw if reached; only the empty branch is exercised.

FinalState.publish implements the CalculateFinalStat suffix: replace final state, apply explicit known-field overrides, call OnIntStatChanged if INT differs (previous missing state means zero), then StatObservable.Updated and MicroPlayObservable.Updated. A failing callback preserves final state and prior side effects and prevents subsequent callbacks. The caller retains the original ItemStat-null guard, composition/provider loading and full skill multicast. Callbacks expose updated INT for AP calculation; this component sends no invented message and writes no independent transaction.

The .NET Framework oracle extracts ApplyStatSkills, ApplyItemSkills and CalculateFinalStat, and compiles the original CharacterStats and Stats files unchanged. Its argument provider, owner and AP/observer callbacks are owned synthetic instrumentation. Each architecture executes 800 formula cases, eight empty-Gear cases and 32 manager callback cases, including override order, null ItemStat, absent previous final state, and injected callback failures. Only the synthetic results and hashes are public; extracted methods stay in ignored cache.

An additional private diagnostic binds the actual base-stat profile and two skills/five arguments to this kernel, using explicitly synthetic zero title/set/status inputs. It reports booleans/counts only, opens no database and is not a complete initializer check. These private initial inputs also produce different results across architectures, so the binding is an actual integration blocker.
