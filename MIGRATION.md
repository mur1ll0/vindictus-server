# Memória da migração Vindictus .NET para Rust

Atualizado em 2026-10-12 (America/Sao_Paulo).

## Objetivo e critério de conclusão
Migrar os serviços antigos e regras de jogo para Rust, executáveis em Docker, preservando compatibilidade com um cliente legado identificado. Conclusão exige login pelo jogo, personagem, inventário, lobby, batalha, recompensa, reconexão e persistência. Infraestrutura saudável e C# descompilado não significam migração completa.

## Estado atual
Migração completa: **NÃO CONCLUÍDA**. Nenhum cliente pode autenticar no serviço Rust atual. O serviço publica HTTP operacional e provisiona contas novas para testes da base, independentes do passport legado. Os 29 usuários de dbo.User foram copiados para PostgreSQL com quinze campos preservados, replay idempotente e comparação após reinício; isso não ativa suas credenciais.

SQL Server é a referência restaurada para comparar o legado. PostgreSQL é o alvo da implementação Rust nova. A migração de dados/regras T-SQL ainda depende do catálogo, do mapeamento de tipos e da paridade de resultados.

## Dependências ainda não resolvidas
- Código nativo não recuperável pelo ILSpy: NMLinkW, NMServer e componentes de rede/proteção; interfaces managed de wrappers não são implementação nativa.
- Estados de autenticação e sessão de jogo; diagnóstico TCP de recusa não substitui LoginService, personagens ou batalha.
- Compatibilidade efetiva cliente/servidor; execução da cópia confirma ingresso no probe, mas autenticação, precedência geral, criação/seleção e cidade continuam pendentes.
- Conversão das regras SQL Server, procedures, tipos e collation; contas PostgreSQL atuais são uma entidade nova.
